# Painting2Code

Project page for **Painting2Code: Can a Model Paint a Painting, or Only Replay Its Pixels?**

Live page: https://primerl.github.io/painting2code/

Painting2Code evaluates whether multimodal coding agents can rebuild museum masterpieces as
executable, editable programs. Each submission is scored on two decoupled pillars: an
image-conditioned rubric tree for visual quality, and an executed editability probe that edits
the source, re-renders it, and measures where the pixels moved.

Artwork images: Art Institute of Chicago and The Metropolitan Museum of Art (public domain),
The Cleveland Museum of Art (CC0).
